DockPin 1.0.1: a new app icon, and virtual displays no longer move the Dock.

![The Dock on the left edge of the center monitor](https://raw.githubusercontent.com/iosifnicolae2/DockPin/main/docs/dockpin-screens.png)

**What's new**
- A new app icon: a Liquid Glass Dock with three dots on a soft pastel background, built like Apple's own icons. macOS 26 and later draw it in Liquid Glass; older versions get a matching flat icon.
- A matching menu-bar icon.
- Virtual displays (from screen recorders or test tools) are left out: one coming or going no longer changes which monitor counts as the center, and DockPin never moves them.

**Install**
1. Download `DockPin.zip`, unzip it, and move `DockPin.app` to Applications (replace the old one).
2. Open it. Its icon appears in the menu bar.
3. Allow Accessibility when macOS asks (System Settings > Privacy & Security > Accessibility).

Requires macOS 14 or later. Signed with Developer ID and notarized by Apple.
[How it works](https://github.com/iosifnicolae2/DockPin/blob/main/docs/how-it-works.md) explains the approach and its trade-offs.
